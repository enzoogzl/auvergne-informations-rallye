# APEX RALLYE — média indépendant (version de travail)

Site vitrine responsive centré sur les reportages et la photographie, avec agenda régional et carte de repérage.

## Prévisualisation locale
Depuis ce dossier :
`python -m http.server 8000`
Puis ouvrir http://localhost:8000

## Publication gratuite
1. Décompresser le ZIP.
2. Déposer le dossier sur https://app.netlify.com/drop ou publier avec GitHub Pages.
3. Vérifier le rendu mobile et les liens avant diffusion publique.

## Avant lancement officiel
- APEX RALLYE est un nom créatif provisoire : vérifier disponibilité INPI, nom de domaine et réseaux sociaux avant adoption.
- L'adresse contact@apexrallye.fr est un exemple à créer/remplacer.
- Les images distantes sont des visuels de démonstration provenant d'Unsplash, pas des photographies originales du média. Les remplacer par tes propres clichés avec crédits et autorisations.
- Les événements sont des repères de calendrier issus de la Ligue Rhône-Alpes ; vérifier chaque date auprès de l'organisateur. Les coordonnées de carte sont approximatives.
- Aucun tracé de spéciale, horaire, accès public, résultat ou classement n'est inventé. Ajouter uniquement des documents officiels à jour.
- Le site est une première version front-end : pas encore de back-office, gestion de comptes, publication d'articles, base de données, commentaires ni hébergement.
- Carte Leaflet et tuiles OpenStreetMap : respecter les conditions d'utilisation du fournisseur, notamment en cas d'audience importante.
